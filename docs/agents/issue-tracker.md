# Issue tracker: GitHub

Issues and PRDs for this repository live as GitHub issues. Use the `gh` CLI for operations and infer the repository from the configured remote.

## Conventions

- Create an issue with a concise title and complete Markdown body.
- Read the issue body, comments, and labels before changing its state.
- Apply or remove labels using the canonical mapping in `triage-labels.md`.
- Close an issue only after its acceptance criteria are verified, with a final evidence comment.
- A request to publish to the issue tracker means creating a GitHub issue.
