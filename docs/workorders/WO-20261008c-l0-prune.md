## 任務

新增 `agent-glue/src/l0-prune.js` 與 `tests/l0-prune.test.mjs`。目的：問任何模型之前，先用零成本規則剪掉工具輸出裡的雜訊（每少一塊＝少一次 Jev 呼叫）。設計見 `/Users/51mini/dev/jev-gate-mcp/docs/prd/PLAN-20261008-laya-first-cascade.md`「L0」段。

`agent-glue/src/l0-prune.js` **不得有任何 import**（Claude Code function hook 與 opencode/Bun 都要能直接載入；`tests/no-node-globals.test.mjs` 的規則：不得出現 `process`、`require`、`Buffer` 等 node 全域）。匯出四個純函式：

1. `stripAnsi(text)`：移除 `/\x1b\[[0-9;?]*[ -\/]*[@-~]/g` 與 `/\x1b\][^\x07]*\x07/g`。
2. `collapseProgress(text)`：逐行處理；一行內含 `\r` 時只留最後一個 `\r` 之後的內容（行尾的單一 `\r\n` 的 `\r` 不算，先把 `\r\n` 換成 `\n`）。
3. `collapseRepeats(text, { min = 3 } = {})`：連續 ≥min 行完全相同 → 保留第一行，下一行換成 `[l0: repeated <N> more times]`（N＝重複次數減 1）。少於 min 原樣保留。
4. `l0Prune(text, opts)`：依序套 stripAnsi → collapseProgress → collapseRepeats，回傳 `{ text, savedChars }`，`savedChars = 原長度 - 新長度`。輸入不是字串時原樣回傳 `{ text, savedChars: 0 }`。

測試（`node:test`＋`node:assert/strict`）至少：
- `stripAnsi('\x1b[31mred\x1b[0m')` 等於 `'red'`。
- `collapseProgress('10%\r50%\r100%\ndone')` 等於 `'100%\ndone'`；`'a\r\nb'` 等於 `'a\nb'`。
- 5 行 `'x'` 接 `'y'` → `'x\n[l0: repeated 4 more times]\ny'`；2 行 `'x'` 不變。
- `l0Prune` 對沒雜訊的文字 `savedChars === 0` 且文字不變；對 `null` 回 `{text:null, savedChars:0}`。
